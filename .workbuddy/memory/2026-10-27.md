# 2026-10-27

## 文章分享接口缺失审计（静态代码审计）

结论：文章模块后端无任何分享入口，但积分与装饰活动两侧都已配置依赖「分享行为」，属于接口缺失而非纯前端功能。

- `src/modules/article/article.controller.ts`：全部路由（create/list/drafts/recommend/search/hot-search/liked/favorited/disliked/:id CRUD/like/favorite/dislike/browse）无 share 路由。
- `src/modules/article/entities/article.entity.ts:85-95`：只有 views / likes / favoriteCount / commentCount，无 shares 计数列。
- `src/modules/points/points-activities.seed.ts:129`：`SHARE_ARTICLE`（10 分、日限 5、sort 9）已 seed，但 `points-event.service.ts` 无 `article.shared` 监听，该规则永远不触发。
- `src/modules/decoration/decoration.service.ts:650`：`incrementProgress` 有 `"shares"` 分支、实体有 `currentShares`/`requiredShares`，但无调用方；`updateLikeProgress`/`updateCommentProgress` 有对应实现，`updateShareProgress` 缺失，`buildArticleActivityWhere` 类型仅 `"LIKE" | "COMMENT"`，故 SHARE 类装饰活动永远无法完成。
- `docs/points-system.md:76`：文档已把 SHARE_ARTICLE 列为正式积分规则。
- `points/add` 走 `@Permissions("points:manage")`，前端无法自增积分，无法绕过。

若补齐，最小方案：`POST /article/:id/share`（匿名可记录、登录才计分/计活动进度）+ entity 加 `shares` 列（幂等 SQL 迁移）+ 事件 `article.shared` → PointsEventService / DecorationEventService。若不补齐，应反向删除 seed 规则与 shares 分支，避免运营配置后永不触发。

## 文章分享接口已补齐（实现）

用户确认「需要补齐」后落地，`npx tsc --noEmit` 通过。

- `article.entity.ts`：新增 `shares`（default 0），位置在 `commentCount` 之后。
- `article.service.ts`：新增 `share(articleId, shareDto?, user?, clientIp?)`；仅 PUBLISHED 可分享（否则 404）；用 cacheManager 做 24h 去重（key `article:share:{articleId}:u{userId}|ip{ip}`，常量 `SHARE_DEDUPE_TTL`）；命中去重则 `counted:false` 不自增；未登录只计数、不发事件；两个计数器私有方法的 field 联合都扩了 `"shares"`。
- `article.controller.ts`：`POST /article/:id/share`，`@UseGuards(JwtAuthGuard) + @NoAuth()` 可选鉴权，IP 用 `@Ip()`（Nest 的 `Request` 类型没有 `ip` 字段，用 `@Req` 取会编译报错）。
- `points-event.service.ts`：新增 `handleArticleShared` → `addPointsByRule(userId, "SHARE_ARTICLE", "ARTICLE", articleId)`。
- `decoration.service.ts` / `decoration-event.service.ts`：新增 `updateShareProgress` 与 `article.shared` 监听；`buildArticleActivityWhere` 类型扩到 `"SHARE"`。
- `statistics.service.ts`：engagement 增加 `articleShares`（SUM(article.shares)）。
- 新增 `docs/2026-10-27-article-share-count.sql`；`docs/events.md`、`docs/points-system.md` 已同步。
- 待办：前端词典需补 `response.success.articleShared`；`channel` 参数已进事件 payload 但暂无消费者；仓库 ESLint 配置缺 `eslint-plugin-prettier`，无法跑 lint（非本次引入）。
